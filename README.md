# home

Source of [www.mboniz.com](https://www.mboniz.com): Marco Bonizzi's personal homepage.

A single static `index.html`, no build step. A side-scrolling run through Milan rendered with three.js (loaded from a CDN); four stops along the way open cards linking to LinkedIn, Strava and two YouTube videos.

- `?style=real` shows the earlier lit-3D look instead of the default poster look.
- Served by GitHub Pages from `main`.
